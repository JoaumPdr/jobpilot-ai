## Uso

`load_skill_taxonomy()` lê as 184 habilidades em 9 categorias do arquivo versionado. A instância pode ser reutilizada para consultar vários termos.

- `taxonomy.lookup(" banco de dados relacional ")` resolve `Relational Databases`.
- `taxonomy.unrecognized_terms(["Python", "Ômega", "omega"])` devolve `{"omega": 2}`.

O relatório conta apenas termos não vazios enviados pelo chamador. Os nomes das categorias vêm das tabelas do TOML. Para acrescentar uma habilidade, edite a tabela da categoria correspondente e verifique o catálogo com `uv run pytest tests/unit/test_skill_taxonomy.py`.
